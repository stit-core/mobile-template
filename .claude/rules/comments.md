# Комментарии

**Default — не писать комментарий.** Хорошее имя функции/типа уже объясняет WHAT. Комментарий допустим, только если без него читатель не догадается о **WHY** — скрытый инвариант, неочевидное ограничение, workaround под конкретный баг, поведение которое удивит.

## Запрещено

- **Restate WHAT.** `// возвращает пользователя по id` над `getUserById` — нет.
- **Narration.** Многострочный пересказ "сначала делаем X, потом Y, наконец Z". Код это и так показывает.
- **Архитектурные эссе в KDoc/DocC.** Не описывай pattern/принципы рядом с реализацией — это место для `docs/` или `CLAUDE.md`.
- **Tombstones.** `// убрано X`, `// раньше был Y` — нет, для этого есть git log.
- **Reference to current task/PR.** `// добавлено для фичи X`, `// fix для #123` — это в commit message, не в коде.
- **Flavor commentary.** Художественный пересказ того, что и так видно.
- **TODO/FIXME.** В коде не живут (detekt `ForbiddenComment`); незакрытое — строкой в `.claude/plans/roadmap.md`.
- **Section dividers.** `// ===== Helpers =====` — файл и так структурирован; длинный файл — разбей.

## Допустимо (одна короткая строка, по-русски)

- WHY-инвариант: `// expect/actual вместо runtime-детекции: платформа известна при компиляции.`
- Workaround: `// kspTest порождает test-классы даже без тестов — Gradle 9 счёл бы это «тесты не найдены».`
- Сюрпризное поведение: `// Keychain переживает удаление приложения — чистим по флагу первого запуска.`
- Хитрая константа: `// 15 мин = TTL access-токена бэкенда; refresh раньше — лишний трафик.`

Примеры формы:

```kotlin
// Ключ живёт вне репозитория (Vaultwarden); путь и пароли — только из env процесса сборки.
val keystorePath = providers.environmentVariable("STIT_KEYSTORE_PATH")
```

```swift
// Синхронизация Keychain в iCloud выключена: refresh-токен привязан к устройству.
query[kSecAttrSynchronizable as String] = kCFBooleanFalse
```

## Исключение: KDoc как метаданные платформы

Единственный законный многострочный KDoc — там, где его читает **не человек, а платформа**:
функции реестра AppFunctions (`@AppFunction(isDescribedByKDoc = true)` в
`core:platform/…/action/AppFunctions.kt`) отдают ассистенту описание, параметры и возврат именно
из KDoc. Такой блок — контракт с системой, а не документация: держи его коротким, в словах
пользователя и без архитектурных пояснений. Везде, где платформа KDoc не читает, правило выше
работает без послаблений.

## Чек

Больше **одной строки** — почти наверняка лишнее: вырази именем/структурой, а «почему так» — в `docs/reference/*`, не в коде. После правки глянь diff: добавленный комментарий объясняет невидимое из кода? Нет — удали.
