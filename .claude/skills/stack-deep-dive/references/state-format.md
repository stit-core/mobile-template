# Формат заметки `state/<kind>.md`

Память скилла — рабочее состояние знания о платформенном артефакте. **Не журнал**.

Лежит рядом со скиллом (`.claude/skills/stack-deep-dive/state/`) и **коммитится** — общая
проектная память между сессиями и архитекторами. Не часть канона `docs/stack/` (туда уходят
зафиксированные решения). Forward-only: только текущее открытое, без «было/стало» и дат сессий.

Kinds — фиксированные singleton'ы, путь плоский: `state/<kind>.md`.

## Шаблон

```markdown
---
kind: deep-links
ref: docs/stack/deep-links.md
---

## Открытые вопросы
- Отпечаток Play app-signing ещё не получен (аккаунт в verification) — таблица отпечатков неполная (**blocker**)
- Нужен ли хост `<domain>` кроме `app.<domain>`?

## Платформенные решения
- Custom scheme `acme://` — только для QR и писем; в push и вебе — https-URL.

## Что копать дальше
- После отпечатков — обновить `signing.md#fingerprints` и INFRA-HANDOFF `MOBILE_ANDROID_SHA256_PLAY`.
```

## Frontmatter

| ключ | значение |
|---|---|
| `kind` | один из 16 kinds |
| `ref` | путь к артефакту от корня репо |

## Секции (все опциональны)

- `## Открытые вопросы` — одна строка на вопрос; суффикс `(**blocker**)` блокирует stable.
  Закрытый вопрос удаляется. Формулировка falsifiable. Cross-kind blocker помечается в
  state rollup'а, который недополучил (`state/config.md` → «`push` объявил `PUSH_PROVIDERS` —
  добавить в build-time (**blocker**)»).
- `## Платформенные решения` — «<что выбрано> — <почему>», без дат; растворилось в артефакте
  — удалить отсюда.
- `## Что копать дальше` — задачи, не вопросы; выполнено — удалить.

## Жизненный цикл

- Создаётся, когда есть что записать; перезаписывается свободно.
- Все секции пусты → удалить файл.
- Артефакт `stable` без blocker'ов — файл может остаться только с непустыми
  `## Платформенные решения`.

## Что не хранить

Историю изменений; журнал сессий; дубликаты содержимого артефакта (хосты, id — в самом
артефакте); подсказки модели «обычно делают так» — это не решение архитектора; сырьё режима B
после разбора.
